A **Phase Space for Computation** is not derivable from the ten UPT postulates alone. To obtain one, UPT must be extended by a precise computational postulate set. The exact postulates required are as follows.

---

# 1. Target object

A computational phase space is a tuple

\[
\mathfrak C
=
\left(
\mathcal B,
\mathcal C,
\mathsf T,
\mathsf R,
\epsilon
\right),
\]

where:

- \(\mathcal B\) is a set of distinguishable computational states,
- \(\mathcal C\) is a set of admissible controls or inputs,
- \(\mathsf T\) is a transition map or relation,

  \[
  \mathsf T:\mathcal C\times\mathcal B\to\mathcal B,
  \]

- \(\mathsf R\) is a readout map,

  \[
  \mathsf R:\mathcal B\to\{0,1\}^m,
  \]

- \(\epsilon>0\) is a stability or error margin.

For universal computation, the transition maps generated by \(\mathcal C\) must contain a universal gate algebra.

---

# 2. UPT postulates already required

The following UPT postulates are necessary but not sufficient.

| UPT Postulate | Required Role |
|---|---|
| I. Phase Primacy | Computation must arise from \(\Phi\), not from primitive computational ontology. |
| II. Structural Configuration | Computational states are phase configurations \(\Phi\in\mathcal C_\Phi\). |
| III. Admissibility | Computational states must satisfy \(\mathscr F[\Phi;\lambda]=0\). |
| IV. Stability | Computational states must be stable or metastable under \(\mathscr L_\Phi\). |
| V. Transition | State changes must occur through phase transitions or controlled branch changes. |
| VI. Emergence | Computational observables must be functionals of \(\Phi\). |
| VII. Topological Protection | Provides robust state labels, but must be supplemented by controlled rewrite ability. |
| VIII. Universality | Allows computational behavior to be insensitive to microscopic phase details. |
| IX. Relational Observability | Readout must be invariant under \(\mathscr G_\Phi\). |
| X. Scale Dependence | Computation is an effective coarse-grained organization of phase structure. |

These postulates provide the phase-theoretic substrate. They do not produce a computational phase space by themselves.

---

# 3. Additional exact postulates required

The following postulates are the minimal additional structure needed to derive, rather than merely encode, a Phase Space for Computation.

---

## C1. Finite Stable Code-Sector Postulate

There exists a finite nonempty set of phase sectors

\[
\mathcal B
=
\{b_1,\dots,b_N\}
\]

with representatives

\[
\Phi_b\in\mathcal C_\Phi
\]

such that:

\[
\mathscr F[\Phi_b;\lambda_0]=0,
\]

\[
\left.
\operatorname{Spec}(\mathscr L_{\Phi_b})
\right|_{\perp}
\subset
[\gamma,\infty),
\qquad
\gamma>0,
\]

and each sector is isolated in the physical phase space

\[
\mathcal P_\Phi
=
\mathcal C_\Phi/\mathscr G_\Phi.
\]

Also,

\[
\dim\mathcal M_b<\infty,
\]

where \(\mathcal M_b\) is the moduli space of physically equivalent configurations near \(\Phi_b\).

This supplies the computational state set.

Without C1, UPT has no finite computational alphabet.

---

## C2. Computational Distinguishability Postulate

Using the UPT phase-response metric

\[
g_{ij}^{\Phi}
=
T_{ia}\chi^{ab}T_{jb},
\]

with

\[
\chi^{ab}
=
\left(
\left.
\mathscr L_{\Phi}
\right|_{\perp}^{-1}
\right)^{ab},
\]

there exists a minimum phase distance

\[
\delta>0
\]

such that for all distinct computational states,

\[
D_{\Phi}(\Phi_b,\Phi_{b'})
\ge
\delta,
\qquad
b\neq b'.
\]

Equivalently,

\[
\min_{b\neq b'}
D_{\Phi}(b,b')
>
0.
\]

This supplies robust distinguishability of computational states.

Without C2, phase sectors cannot serve as reliable logical states.

---

## C3. Phase Chronodynamics Postulate

There exists an admissible phase evolution law

\[
\frac{d\Phi}{dt}
=
\mathscr K[\Phi;\lambda(t)]
\]

or, more generally, a well-defined transition operator

\[
\mathscr U_{t_2,t_1}:
\mathcal P_\Phi\to\mathcal P_\Phi,
\]

such that phase evolution is time-ordered and compatible with admissibility:

\[
\mathscr F[\Phi(t);\lambda(t)]=0
\]

or is driven through controlled admissible paths in the space of solutions.

This supplies the ordering required for computation.

Without C3, UPT gives static phase structure but no computational process.

---

## C4. Controlled Transition Postulate

There exists a control space

\[
\mathcal C
\]

such that each control \(c\in\mathcal C\) defines an admissible phase path \(\lambda_c(t)\) and induces a well-defined map

\[
\mathsf T_c:\mathcal B\to\mathcal B
\]

by

\[
\mathscr U_c([\Phi_b])
=
[\Phi_{\mathsf T_c(b)}].
\]

The control mechanism must be internal to UPT or derivable from phase structure. It must not be an externally inserted classical controller unless that controller is itself represented as a phase sector.

If computational sectors are topologically distinct, then C4 additionally requires the existence of finite-energy, admissible sector-change channels:

\[
q[\Phi_{\mathsf T_c(b)}]
\neq
q[\Phi_b]
\]

must be achievable without uncontrolled singularities.

This supplies gates and state transitions.

Without C4, stable phase sectors exist but cannot be rewritten.

---

## C5. Logical Composition and Universality Postulate

The controlled transition maps must compose:

\[
\mathsf T_{c_2}\circ\mathsf T_{c_1}
=
\mathsf T_{c_2c_1}.
\]

There must exist an identity operation,

\[
\mathsf T_{\mathrm{id}}
=
\mathrm{id}_{\mathcal B},
\]

and a physically realizable composition mechanism.

For universal computation, the monoid generated by the controlled transitions must contain a universal gate algebra:

\[
\left\langle
\mathsf T_c
:
c\in\mathcal C
\right\rangle
\supseteq
\mathcal G_{\mathrm{univ}},
\]

where \(\mathcal G_{\mathrm{univ}}\) may be generated, for example, by a Toffoli gate, a NAND gate with ancilla and reset, or an equivalent universal reversible gate set.

This supplies actual computation rather than mere state transition.

Without C5, UPT may produce a finite-state system but not a universal computer.

---

## C6. Preparation and Input-Encoding Postulate

There exists an encoding map

\[
\iota:
\{0,1\}^n
\to
\mathcal B
\]

such that each input string \(x\) is represented by a stable phase sector

\[
\Phi_{\iota(x)}.
\]

The encoding must be robust:

\[
D_\Phi(\iota(x),\iota(y))
\ge
\delta,
\qquad
x\neq y.
\]

There must also exist a preparable initial or reset sector

\[
b_0\in\mathcal B.
\]

This supplies inputs and initialization.

Without C6, the phase system has states but no computational input convention.

---

## C7. Readout Postulate

There exists a phase observable

\[
\mathsf R[\Phi]
\]

satisfying phase invariance,

\[
\mathsf R[g\cdot\Phi]
=
\mathsf R[\Phi],
\qquad
g\in\mathscr G_\Phi,
\]

and a decode map

\[
\rho:
\operatorname{Range}(\mathsf R)
\to
\{0,1\}^m
\]

such that

\[
\rho(\mathsf R[\Phi_b])
=
\mathsf R(b).
\]

The readout must be stable under perturbations below the computational error margin.

This supplies outputs.

Without C7, computation may occur internally but has no observable result.

---

## C8. Error-Stability Postulate

There exists an error margin

\[
\epsilon>0
\]

such that for every code sector \(b\) and every perturbation \(\delta\Phi\) satisfying

\[
\|\delta\Phi\|_\Phi
<
\epsilon,
\]

the computational label is preserved:

\[
\operatorname{label}([\Phi_b+\delta\Phi])
=
b.
\]

More generally, if exact preservation fails, there exists an admissible recovery operation \(\mathcal R\) such that

\[
\operatorname{label}
\left(
\mathcal R([\Phi_b+\delta\Phi])
\right)
=
b.
\]

This supplies reliable computation.

Without C8, phase noise destroys computational meaning.

---

## C9. Finite Information-Density Postulate

For any bounded region of effective phase space, the number of mutually distinguishable stable computational sectors is finite.

Formally, for phase balls of radius \(R\),

\[
N(R)
=
\sup_{\Phi_0}
\#
\left\{
b:
D_\Phi(b,\Phi_0)\le R
\right\}
<
\infty.
\]

This prevents an uncontrolled continuum of computational states.

Without C9, the phase system may have infinite capacity but no finite, robust computational encoding.

---

## C10. Predictive Action-Selection Postulate

The universal phase action \(\mathcal S_\Phi\) must be fixed by independent axioms, or the computational observable map must be rank-deficient.

Let

\[
\mathcal O:
\Theta
\to
\mathbb R^M
\]

map the free phase-action data \(\Theta\) to computational observables.

The theory is predictive only if either:

1. \(\Theta\) is fixed by principle, or  
2. most parameter directions are unobservable gauge directions, or  
3. the rank satisfies

   \[
   r
   =
   \operatorname{rank}
   \left(
   \frac{\partial\mathcal O_i}{\partial\theta_j}
   \right)
   <
   M.
   \]

If

\[
r=M
\]

and

\[
\dim\Theta_{\mathrm{free}}
\ge
M,
\]

then the computational phase space is fitted, not derived.

Candidate action-fixing axioms include:

- phase covariance,
- locality in phase configuration space,
- boundedness and vacuum stability,
- reparameterization invariance,
- finite phase information density,
- topological consistency,
- existence of a stable vacuum sector.

At present, no known axiom set has been proven to uniquely fix \(\mathcal S_\Phi\).

Without C10, any computational phase space can be engineered by tuning \(V_\Phi\), \(G^{AB}\), \(\mathcal A_A\), or \(\mathcal S_{\mathrm{topo}}\).

---

# 4. Minimal sufficient set

A classical Phase Space for Computation is obtained if the following hold:

\[
\boxed{
\text{UPT I--X}
+
\text{C1--C10}.
}
\]

More explicitly:

\[
\boxed{
\text{UPT}
+
\text{Finite Stable Sectors}
+
\text{Distinguishability}
+
\text{Phase Dynamics}
+
\text{Controlled Transitions}
+
\text{Logical Composition}
+
\text{Input Encoding}
+
\text{Readout}
+
\text{Error Stability}
+
\text{Finite Capacity}
+
\text{Predictive Action Selection}.
}
\]

For universal computation, C5 must include a universal gate algebra.

For quantum computation, the following additional postulates are required.

# 5. Additional postulates for quantum computation

If the desired Phase Space for Computation is quantum, add:

## Q1. Phase Quantization Postulate

The reduced physical phase space admits a Hilbert space \(\mathcal H\).

## Q2. Unitarity Postulate

Phase evolution is represented by unitary operators,

\[
U(t_2,t_1):
\mathcal H\to\mathcal H,
\qquad
U^\dagger U=I.
\]

## Q3. Born-Rule Postulate

Measurement probabilities are given by

\[
P_i
=
\|P_i\Psi\|^2,
\]

where \(P_i\) is the projector onto the \(i\)-th outcome subspace.

## Q4. Tensor Composition Postulate

Composite computational systems obey

\[
\mathcal H_{AB}
=
\mathcal H_A\otimes\mathcal H_B.
\]

Without Q1–Q4, UPT does not derive quantum computation.

# 7. Final statement

The exact postulates needed are:

\[
\boxed{
\text{UPT Postulates I--X}
}
\]

together with the additional computational postulates

\[
\boxed{
\text{C1--C10}.
}
\]

For quantum computation, add

\[
\boxed{
\text{Q1--Q4}.
}
\]

UPT alone does not supply these computational postulates. Therefore a Phase Space for Computation is not presently a consequence of UPT itself. It becomes a consequence only of the extended theory

\[
\boxed{
\mathrm{UPT+C}.
}
\]
