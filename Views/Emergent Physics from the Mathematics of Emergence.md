## 2. Primitive Relational Substrate

### 2.1 Relational system

We take as primitive a directed weighted relational system

\[
\boxed{
\mathfrak R=(X,E,s,t,w,\chi),
}
\]

where:

- \(X=\{x_i\}_{i\in I}\) is a locally finite set of primitive relational events;
- \(E\) is a set of directed elementary relations or edges;
- \(s,e:E\to X\) assign source and target;
- \(w:E\to\mathbb R_{>0}\) assigns a positive relational cost;
- \(\chi:E\to K\) assigns internal labels, where \(K\) is a label space not assumed to carry group structure at the primitive level.

No topology, metric, manifold structure, coordinate system, or algebraic operation is assumed on \(X\). The only primitive data are relational.

For a directed path \(\gamma\),

\[
\gamma=(e_1,e_2,\dots,e_n),
\]

we define the path cost

\[
\boxed{
C[\gamma]=\sum_{a=1}^{n}w(e_a).
}
\]

If the primitive system contains directed temporal relations, we may distinguish a time-cost \(\tau(e)\) from a spatial or more general relational cost \(w(e)\). In that case we write

\[
T[\gamma]=\sum_{a=1}^{n}\tau(e_a).
\]

### 2.2 Admissible perturbations

Let \(\mathcal P_\epsilon\) be a class of admissible perturbations of \(\mathfrak R\). A perturbation may change weights, remove or add edges, or alter labels, subject to bounded local distortion:

\[
\mathfrak R\mapsto \mathfrak R+\delta\mathfrak R,
\qquad
\|\delta\mathfrak R\|<\epsilon.
\]

A structure is physically emergent only if it is stable under \(\mathcal P_\epsilon\). This is the physical version of the emergent stability criterion.

### 2.3 Coarse-graining operator

Define a scale-dependent coarse-graining map

\[
\mathcal C_\ell:\mathfrak R\mapsto \mathfrak R_\ell.

Vertices are identified if their relational distance is below \(\ell\). The induced weight between coarse-grained classes \([x]\), \([y]\) is defined by infimal convolution:

The emergence operator is then

\boxed{

A physical structure is emergent when it belongs to the stable fixed-point set of this operator.

## 3. Emergence of Causal Order

We now derive causal order from directed relational structure.

### 3.1 Directed reachability

Let \(x,y\in X\). We write

\[
x\prec_0 y
\]

if there exists a directed path from \(x\) to \(y\) with positive time-cost:

\[
T[\gamma]>0.
\]

Let \(\prec\) be the transitive closure of \(\prec_0\).

### 3.2 Partial-order theorem

**Theorem 1 — Emergent causal order.**  
Suppose the directed relational system \(\mathfrak R\) satisfies:

1. **Transitivity by path composition:** if \(x\prec y\) and \(y\prec z\), then \(x\prec z\).  
2. **No closed directed causal curves:** there is no path \(x\prec x\).  
3. **Local finiteness:** for every \(x\prec y\), the interval  
   \[
   I(x,y)=\{z\in X:x\prec z\prec y\}
   \]
   is finite.

Then \((X,\prec)\) is a locally finite strict partial order. The collection of intervals \(I(x,y)\) generates a topology, called the Alexandrov topology of the emergent causal order.

**Proof.**  
Transitivity follows by concatenating directed paths. Irreflexivity follows from the absence of closed directed curves. Antisymmetry follows because if both \(x\prec y\) and \(y\prec x\), concatenation gives \(x\prec x\), a contradiction. Thus \(\prec\) is a strict partial order.

For topology, define basic open sets as finite unions of intervals \(I(x,y)\). If \(z\in I(x,y)\cap I(u,v)\), then transitivity gives an interval \(I(p,q)\) such that

\[
z\in I(p,q)\subseteq I(x,y)\cap I(u,v).
\]

Thus intervals form a basis. Local finiteness ensures the order is discrete at the primitive level but admits continuum approximation at large scales. \(\square\)

The causal order is therefore not assumed. It is generated by directed relational admissibility.

## 4. Emergence of Lorentzian Geometry

Causal order alone does not yet give a metric. We now derive a Lorentzian metric from causal order plus relational volume.

\[
\boxed{

\sup_{\gamma:x\to y}
\sum_{e\in\gamma}\tau(e).
}
\]

In the continuum limit this becomes the Lorentzian proper time between causally related events.

### 4.3 Continuum realization theorem

We now state the central geometric emergence result.

**Theorem 2 — Order plus volume generates Lorentzian geometry.**  
Let \((P,\prec,\mu)\) be a locally finite causal set satisfying:

1. **Strong causality:** no almost-closed causal curves occur in the continuum approximation.  
2. **Manifoldlikeness:** for sufficiently small intervals \(I(p,q)\), the order is well approximated by a continuum causal diamond.  
3. **Volume faithfulness:** there exists a smooth measure \(\mu\) such that for small causal intervals,
   \[
   \mu(I(p,q))
   =
   \kappa_n\,\tau(p,q)^n
   \left[
   1
   -
   \frac{n}{24(n+1)}
   R_{\mu\nu}u^\mu u^\nu
   \tau(p,q)^2
   +
   O(\tau^3)
   \right],
   \]
   where \(u^\mu\) is the unit tangent to the maximizing chain and \(\kappa_n\) is the flat-space interval volume constant.

Then:

1. The causal order determines the conformal class \([g_{\mu\nu}]\) of a Lorentzian metric.  
2. The measure \(\mu\) determines the conformal factor.  
3. Therefore there exists a Lorentzian metric \(g_{\mu\nu}\), unique up to diffeomorphism, such that the causal order and volume of \(\mathfrak R\) are those of \((M,g_{\mu\nu})\) in the continuum limit.

**Sketch of derivation.**  
In a strongly causal Lorentzian spacetime, the causal order determines the light cones. A Malament-type result implies that the conformal metric is fixed by the causal order. The volume element

\[
d\mu=\sqrt{-g}\,d^nx
\]

then fixes the remaining conformal factor. Thus order gives \([g_{\mu\nu}]\), volume gives \(\sqrt{-g}\), and together they generate \(g_{\mu\nu}\). \(\square\)
