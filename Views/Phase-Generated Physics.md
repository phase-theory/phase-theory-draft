## Abstract

We develop a physical theory whose primitive object is not spacetime, metric, field, or particle, but relational phase. Starting from a phase-primitive system \(\Phi\) equipped only with phase differences, composition, and admissibility, we derive a hierarchy of physical structures: a \(U(1)\) gauge connection from phase frustration, a Lorentzian metric from multiphase gradients, Einsteinian gravitational dynamics as the low-energy phase-stability functional, quantum mechanics as the coherent dynamics of phase line bundles, and topological matter from phase defects. The construction yields several new physical consequences: a phase-stiffness cutoff, modified dispersion relations, signature-transition hypersurfaces, phase-pressure vacuum energy, and topologically stable Hopfionic particle modes. The central result is that a large part of fundamental physics can be rederived from the generative arrow

\[
\Phi \longrightarrow \text{relations} \longrightarrow \text{invariants} \longrightarrow \text{geometry} \longrightarrow \text{physics},
\]

provided the phase system satisfies explicit rank, stability, and admissibility conditions.

## 1. Phase-Primitive Postulates

Let \(\Phi\) denote a primitive phase system. We do not assume a manifold \(M\), a metric \(g\), a time parameter \(t\), or a field bundle. The only primitive datum is relational phase content.

### Postulate P1: Relational phase

For any two phase states \(i,j\), there is a phase relation

\[
U_{ij} \in U(1),
\]

satisfying

\[
U_{ii}=1,
\qquad
U_{ji}=U_{ij}^{-1}.
\]

When a local phase representation exists, we write

\[
U_{ij}=e^{i\Delta_{ij}\Phi},
\qquad
\Delta_{ij}\Phi=\Phi_i-\Phi_j \pmod{2\pi}.
\]

But the representation is secondary. The primitive object is the relational system \(\{U_{ij}\}\).

### Postulate P2: Phase equivalence

Global phase shifts are pure redundancy:

\[
\Phi_i \mapsto \Phi_i+\alpha
\]

leaves all relational data invariant. The physical phase state is the equivalence class

\[
[\Phi]=\{\Phi+\alpha\}.
\]

The first emergent space is therefore

\[
\mathcal X_\Phi=\mathcal P_\Phi/U(1),
\]

where \(\mathcal P_\Phi\) is the admissible phase configuration space.

### Postulate P3: Admissibility

Not all phase configurations are physically realized. There exists an admissibility functional

\[
\mathscr F[\Phi;\lambda]
\]

such that physical phase configurations obey

\[
\boxed{
\delta \mathscr F[\Phi;\lambda]=0
}
\]

and satisfy a stability condition

\[
\delta^2\mathscr F[\Phi;\lambda]\geq 0
\]

on the physical branch.

### Postulate P4: Emergent locality

Locality is not assumed. It emerges when phase relations decay with phase distance. Define a phase distance

\[
d_\Phi(i,j)=2\left|\sin\frac{\Delta_{ij}\Phi}{2}\right|.
\]

For a multiphase system, this generalizes to

\[
d_\Phi^2(i,j)
=
G_{AB}\Delta\Phi^A_{ij}\Delta\Phi^B_{ij}
\]

for an internal phase metric \(G_{AB}\). A neighborhood system is then generated by

\[
U_\epsilon(i)=\{j:d_\Phi(i,j)<\epsilon\}.
\]

The topology generated by these neighborhoods is the emergent phase topology \(\mathcal T_\Phi\).

## 2. Emergence of \(U(1)\) Gauge Fields from Phase Frustration

Thus electromagnetism is derived as the low-energy theory of phase curvature.

## 3. Emergent Lorentzian Geometry from Multiphase Gradients

A single scalar phase cannot generate a nondegenerate higher-dimensional metric. The rank obstruction is immediate. If

\[
g_{ab}^{(\Phi)}=\partial_a\Phi\,\partial_b\Phi,
\]

\[
\operatorname{rank}(g^{(\Phi)})\leq 1.
\]

\[
\Phi^A,\qquad A=0,1,2,3,

\[
\eta_{AB}=\operatorname{diag}(-1,+1,+1,+1).
\]

Define the induced spacetime metric

\[
\boxed{

=
\eta_{AB}
\partial_\mu\Phi^A
\partial_\nu\Phi^B.
}
\]

Equivalently, define the phase frame

\[
e_\mu{}^A=\partial_\mu\Phi^A,
\]

so that

\[
g_{\mu\nu}
=
\eta_{AB}e_\mu{}^A e_\nu{}^B.
\]

### 3.1 Rank and signature theorem

**Theorem 3.1.** Let \(\Phi^A:M\to \mathbb R^{1,3}\) be differentiable phase fields and define

\[
g_{\mu\nu}
=
\eta_{AB}\partial_\mu\Phi^A\partial_\nu\Phi^B.
\]

Then

\[
\operatorname{rank}(g)\leq \min(\dim M,4).
\]

If the Jacobian \(\partial_\mu\Phi^A\) has rank four, then \(g_{\mu\nu}\) is nondegenerate. Its signature is the signature of \(\eta_{AB}\), namely \((1,3)\) or \((3,1)\), depending on convention.

**Proof.** In matrix notation,

\[
g=J^T\eta J,
\]

where \(J^A{}_\mu=\partial_\mu\Phi^A\). Hence

\[
\operatorname{rank}(g)
\leq
\operatorname{rank}(J)
\leq 4.
\]

If \(J\) is invertible, then for any nonzero \(v^\mu\),

\[
g_{\mu\nu}v^\mu v^\nu
=
\eta_{AB}
(v^\mu\partial_\mu\Phi^A)
(v^\nu\partial_\nu\Phi^B).
\]

Since \(J\) is invertible, \(w^A=v^\mu\partial_\mu\Phi^A\) ranges over all nonzero vectors in \(\mathbb R^{1,3}\). Therefore the inertia of \(g\) equals the inertia of \(\eta\). \(\square\)

Thus Lorentzian geometry emerges when the phase Jacobian has full rank and the internal phase metric has Lorentzian inertia.

### 3.2 Phase distance as line element

The primitive phase distance generalizes to

Spacetime geometry is not imposed. It is induced by phase gradients.

## 5. Quantum Mechanics from Phase Coherence

Quantum mechanics is derived from the geometry of phase line bundles. The wavefunction is not primitive. It is a coherent phase section.

### 5.1 Phase line bundle

Let \(L\to M\) be the complex line bundle generated by phase. A matter field is a section

\[
\psi:M\to L.
\]

Local phase transformations act as

\[
\psi\mapsto e^{iq\alpha(x)}\psi.

The phase connection \(A_\mu\) defines the covariant derivative

\[
\boxed{
D_\mu\psi
=
\left(\partial_\mu-iqA_\mu\right)\psi.
}

The gauge-invariant phase action is

\[
\boxed{
S_{\psi}
=
-\int d^4x\sqrt{-g}
\left[
g^{\mu\nu}(D_\mu\psi)^*D_\nu\psi
+
m^2|\psi|^2
+
V(|\psi|^2)
\right].
}
\]

Varying \(\psi^*\) gives

\[
\boxed{
D_\mu D^\mu\psi
-
m^2\psi
-
V'(|\psi|^2)\psi
=0.
}
\]

In the free case \(V=0\),

\[
\boxed{
(D_\mu D^\mu+m^2)\psi=0
}
\]

up to sign convention. This is the Klein-Gordon equation derived as a phase-admissibility equation.

### 5.2 Phase-current conservation

Write

\[
\psi=\sqrt{\rho}\,e^{iS/\hbar_\Phi}.

Then

\[

+
\frac{i}{\hbar_\Phi}\sqrt{\rho}
\left(\partial_\mu S-q\hbar_\Phi A_\mu\right)

\[
\boxed{
\nabla_\mu
\left[
\rho
\left(
\nabla^\mu S-q\hbar_\Phi A^\mu
\right)
\right]
=0.
}
\]

Define the phase current

\[
\boxed{
J^\mu
=
\rho
\left(
\nabla^\mu S-q\hbar_\Phi A^\mu
\right).
}
\]

Then

\[
\boxed{
\nabla_\mu J^\mu=0.
}
\]

Probability conservation is therefore phase-current conservation.

### 5.3 Quantum Hamilton-Jacobi equation

The real part gives

\[

\left(\nabla_\mu S-q\hbar_\Phi A_\mu\right)

Classical mechanics is recovered when

\[
|Q_\Phi|\ll m^2.

Quantum mechanics is therefore not an independent axiom. It is the dynamics of phase amplitude and phase curvature.

## 6. Topological Matter from Phase Defects

Phase defects are not imperfections added to the theory. They are unavoidable localized structures of the phase-primitive framework.

For a closed loop \(\gamma\),

\[
n_\gamma

\[
\boxed{
\oint_\gamma

2\pi n.

\]

Thus charge is topological phase winding.

### 6.2 Phase strings in four dimensions

\[

=
\frac{1}{2\pi}

\partial_\rho\partial_\sigma\Phi.

Because partial derivatives commute away from singularities,

\[
\partial_\mu J^{\mu\nu}_\Phi=0.
\]

A phase string with winding \(n\) has tension

\[
\boxed{

\sim
\pi v^2 n^2
\log\left(\frac{R}{\delta}\right),

where \(v\) is the phase stiffness scale, \(R\) is the macroscopic cutoff, and \(\delta\) is the core size.

Such strings gravitate. In the weak-field limit, a straight phase string produces a conical deficit

\[
\boxed{
\Delta\varphi
=
8\pi G_\Phi\mu_n.
}
\]

Therefore topological phase defects generate observable gravitational lensing without electromagnetic emission. They are natural phase-primitive dark matter candidates.

### 6.3 Hopfionic matter

A single \(S^1\) phase cannot support Hopf topology because

\[
\pi_3(S^1)=0.

However, a multiphase system can generate a normalized internal vector

\[

\[

\[

Define the Hopf two-form

\frac{1}{4\pi^2}

Stable finite-energy configurations require a Skyrme-Faddeev-type phase stiffness term,

S_{\mathrm{Hopf}}
=
\int d^4x\sqrt{-g}

\alpha\,\partial_\mu\mathbf n\cdot\partial^\mu\mathbf n

The resulting solitons are particle-like phase knots. Their topological charge is \(H\). Their masses scale approximately as

\[
\boxed{

\sim
\kappa\,|H|^{3/4}.
}
\]

These Hopfionic excitations are a new form of matter predicted by phase-primitive theory. They are not quanta of a pre-existing field; they are stable topological organizations of phase.

## 7. New Physical Consequences

The phase-primitive derivation does not merely reproduce known physics. It implies new phenomena.

Phase gradients cannot be arbitrary. Stability of the phase medium imposes

\[
\boxed{
|\partial_\mu\Phi^A|

This is not an arbitrary Planck-scale assumption. It follows from bounded phase distance and phase-admissibility stability.

\[
S_{\mathrm{hd}}

\frac{1}{2\Lambda_\Phi^2}
\int d^4x\sqrt{-g}\,

\Box\Phi^A\Box\Phi^B.

\boxed{

+

+

In flat space, with \(\Box\to -E^2+\mathbf p^2\), the dispersion relation becomes

\boxed{
E^2
=
\mathbf p^2
+
m^2
+
\alpha
\frac{\mathbf p^4}{\Lambda_\Phi^2}

O(\Lambda_\Phi^{-4}).
}

The coefficient \(\alpha\) is determined by the phase-stability functional. This is a testable prediction: high-energy propagation receives phase-stiffness corrections suppressed by \(\Lambda_\Phi^2\).

=

Spacetime singularities are therefore expected to be resolved by phase-rank saturation rather than by infinite curvature.

Dark energy is thereby interpreted as unresolved phase frustration.
