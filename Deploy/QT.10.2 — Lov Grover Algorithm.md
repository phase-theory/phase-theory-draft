Section 56. Lov Grover Algorithm

56.1 Introduction

The preceding section applied the thermodynamic framework to Shor’s algorithm and established that its asymptotic computational advantage can survive the energetic and entropic overhead of fault-tolerant quantum computation.

The next major case is Grover’s quantum search algorithm.

Grover’s algorithm is fundamentally different from Shor’s algorithm.

For an unstructured search problem over a domain of size

[
N,
]

a classical exhaustive search requires

[
\Theta(N)
]

oracle evaluations, whereas Grover’s algorithm requires

[
\Theta(\sqrt N)
]

oracle evaluations.

The computational speedup is therefore quadratic:

[
\boxed{
S_G(N)

\Theta(\sqrt N).
}
]

This creates a more stringent thermodynamic question:

Does a quadratic quantum speedup survive the energy, entropy, fault-tolerance, measurement, and reset costs required to execute Grover’s algorithm physically?

Unlike Shor’s algorithm, whose asymptotic advantage is superpolynomial relative to the best known classical factoring methods, Grover’s advantage is only quadratic.

Consequently, thermodynamic overhead can become asymptotically comparable to the algorithmic speedup.

The central result of this section is that Grover’s algorithm retains asymptotic thermodynamic advantage under favorable architectural assumptions, but its advantage is substantially more sensitive to fault-tolerance overhead, oracle implementation cost, and irreversible search verification.

56.8 Oracle Thermodynamics

The oracle is the central physical component of Grover’s algorithm.

A reversible oracle must implement

[
\boxed{
U_f|x\rangle|b\rangle

|x\rangle
|b\oplus f(x)\rangle.
}
]

Phase-kickback converts this into

[
\boxed{
|x\rangle
\mapsto
(-1)^{f(x)}|x\rangle.
}
]

If the oracle requires

[
G_O
]

physical logical gates, then its thermodynamic cost is

[
\boxed{
W_O

G_O\epsilon_G.
}
]

The total oracle cost is

[
\boxed{
W_{\rm oracle}

k^\star W_O.
}
]

Since

[
k^\star=\Theta(\sqrt N),
]

we obtain

[
\boxed{
W_{\rm oracle}

\Theta(\sqrt N,W_O).
}
]

56.9 Oracle Dominance Principle

In many practical implementations,

[
W_O
\gg
W_D,
]

where

[
W_D
]

is the thermodynamic cost of the diffusion operator.

Therefore,

[
\boxed{
W_{\rm Grover}
\approx
\Theta(\sqrt N,W_O).
}
]

This establishes the Oracle Dominance Principle:

The thermodynamic cost of Grover’s algorithm is determined primarily by the physical complexity of the oracle rather than by the abstract quadratic query count alone.

A quantum search advantage can therefore be thermodynamically diminished if the oracle is energetically expensive.

56.13 Thermodynamic Scaling Theorem for Grover Search

Theorem 56.1

Assume:

1. the oracle has polynomial logical complexity in

[
n=\log_2N;
]

2. the physical error rate satisfies

[
p<p_{\rm th};
]

3. elementary fault-tolerant operations have bounded thermodynamic work;
4. the total failure probability remains bounded by a constant.

Then Grover’s algorithm has total thermodynamic work

[
\boxed{
W_{\rm Grover}

\sqrt N,
\operatorname{poly}(\log N)
(\ln N)^2.
}
]

⸻

Proof

Grover search requires

[
\Theta(\sqrt N)
]

iterations.

Each iteration has polynomial logical complexity in

[
n=\log_2N.
]

Maintaining constant total failure probability requires

[
d=\Theta(\ln N).
]

Fault-tolerant work therefore scales as

[
N_LD_Gd^2,
]

which yields

[
\sqrt N,
\operatorname{poly}(\log N)
(\ln N)^2.
]

□

56.16 The Thermodynamic Fragility of Quadratic Speedup

Although the asymptotic advantage survives, the quadratic speedup is thermodynamically fragile.

Suppose the fault-tolerant overhead is

[
H_{\rm FT}(N).
]

The quantum advantage survives if

[
\boxed{
H_{\rm FT}(N)

o(\sqrt N).
}
]

If instead

[
H_{\rm FT}(N)

\Omega(\sqrt N),
]

then the thermodynamic overhead can erase the asymptotic advantage.

This yields the Quadratic-Speedup Fragility Criterion:

[
\boxed{
\text{Grover advantage survives}
\iff
H_{\rm FT}(N)
<
\sqrt N
\quad
\text{asymptotically}.
}
]

[

[
\boxed{

\Theta

[
\boxed{

\boxed{

Thus, the quantum oracle may be up to a sub-square-root factor more energetically expensive than the classical oracle while preserving asymptotic advantage.

56.22 Grover Thermodynamic Uncertainty Relation

The output search result is a stochastic observable.

Let

The thermodynamic uncertainty relation implies

\boxed{

56.23 Energy–Success Tradeoff

Let

[
P_{\rm succ}
]

be the probability of obtaining the marked state.

The total work required to achieve a target success probability satisfies

[
\boxed{
W_{\rm Grover}
\ge
W_{\min}(P_{\rm succ}).
}
]

Increasing the number of iterations beyond the optimal value does not monotonically improve success probability.

Therefore, thermodynamic optimization requires

[
\boxed{
k_{\rm opt}

\arg\min_k
\left{
W(k):
P_{\rm succ}(k)\ge P^\star
\right}.
}
]

This is the Minimum-Work Search Principle.

56.26 Principle of Thermodynamic Quadratic Advantage

The developments of this section establish the following principle.

Principle of Thermodynamic Quadratic Advantage

A quadratic quantum speedup survives thermodynamic overhead only when the combined energy, entropy, fault-tolerance, oracle, measurement, and reset costs grow asymptotically more slowly than the square root of the classical search space. Under polynomial-logarithmic physical overhead, Grover’s algorithm retains asymptotic thermodynamic advantage, but the advantage is substantially more fragile than the superpolynomial advantage of Shor’s algorithm.
