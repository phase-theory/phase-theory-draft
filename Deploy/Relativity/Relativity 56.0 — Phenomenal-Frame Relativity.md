# Relativity 56.0 — Phenomenal-Frame Relativity  
## First-Person Experience as a Frame of Appearance

**White paper / academic preprint**

---

## Abstract

Phenomenal-Frame Relativity is a cautious naturalistic extension of the relativistic program into phenomenology. It proposes that first-person experience is not an object inside space but a frame through which objects appear. Conscious states are not substances, private theaters, or immaterial atoms. They are organized, integrated, reportable, and shareable frames of appearance. Let \(F_c\) denote a conscious frame and \(N(F_c)\) its neural or functional correlate. Different conscious frames may have different qualitative structures, but their public correlates can be compared, calibrated, and modeled. The central principle is:

\[
\boxed{
\text{Subjective appearance is frame-relative; invariant structure is publicly correlatable.}
}
\]

This framework does not require dualism. It does not claim that consciousness escapes physics. It also does not collapse consciousness into a simple physical object. It treats consciousness as a natural frame of access, analogous in logical status to a reference frame, an Umwelt, or an observational protocol. Phenomenal-Frame Relativity avoids both naive objectivism, which treats qualia as ordinary physical objects, and unconstrained subjectivism, which treats first-person experience as scientifically inaccessible. It proposes that the scientifically tractable core of consciousness is the invariant relational structure that can be correlated across reports, behaviors, neural states, and experimental interventions.

## 1. Introduction

Physics has learned to treat observation as framed.

Special relativity showed that simultaneity is frame-dependent.

General relativity showed that geometry is measured relative to physical observers.

Quantum mechanics showed that measurement outcomes depend on experimental context.

Embodied-Observer Relativity showed that observation depends on sensorimotor capacity.

Umwelt / Biological Frame Relativity showed that species inhabit different operational worlds.

Phenomenal-Frame Relativity takes one further step.

It asks:

\[
\text{What about first-person experience itself?}
\]

When one sees red, feels pain, hears a sound, or recognizes oneself in time, there seems to be something it is like to undergo that state.

Phenomenal-Frame Relativity treats this “something it is like” not as a hidden object inside the skull, but as a frame of appearance.

A conscious frame is a perspective through which the world is organized.

It is not itself another object in the world.

It is the condition under which objects are given.

Thus:

\[
\boxed{
\text{Consciousness is not a thing among things. It is a frame of appearing.}
}
\]

This is not a mystical claim.

It is a structural claim.

A frame is not an object inside the frame.

A coordinate system is not a point in the coordinate system.

A visual field is not simply another visual object inside the visual field.

A first-person perspective is not simply another object inside the world it discloses.

Thus consciousness is frame-like.

## 2. The Core Principle

The central principle is:

\[
\boxed{
\text{Subjective appearance is frame-relative; invariant structure is publicly correlatable.}
}
\]

This has two halves.

First, subjective appearance is frame-relative.

What appears, how it appears, and what can be reported depend on the conscious frame.

Second, invariant structure is publicly correlatable.

Even if first-person appearance is not directly observable as an object, its structure can be correlated with behavior, report, neural dynamics, and experimental manipulation.

Thus science does not need to observe qualia as physical objects.

It can study the invariant structures that stable conscious frames produce.

## 11. First-Person and Third-Person Asymmetry

There is an asymmetry between first-person and third-person access.

A subject has direct access to their own conscious frame.

An external observer has indirect access through behavior, report, and neural measurement.

But this asymmetry does not imply dualism.

It is analogous to frame asymmetry in physics.

An observer inside a frame has access to certain facts relative to that frame.

An external observer has access to a different set of relational facts.

The two perspectives are not necessarily contradictory.

They are different frames of access.

Thus:

\[
\boxed{
\text{First-person access is frame-relative access, not metaphysical privacy.}
}
\]

## 13. Avoiding Unconstrained Subjectivism

Unconstrained subjectivism says that because experience is first-personal, it is scientifically unconstrained.

Phenomenal-Frame Relativity rejects this.

A conscious frame is scientifically meaningful only if it has stable correlates.

These include:

1. reproducible reports,
2. behavioral consequences,
3. neural signatures,
4. causal manipulability,
5. cross-subject comparability,
6. temporal stability,
7. perturbation response.

Thus not every claimed experience is equally scientifically tractable.

Reports must be calibrated.

Phenomena must be stabilized.

Structures must be correlated.

Thus:

\[
\boxed{
\text{Subjectivity is real, but not arbitrary.}
}
\]

## 16. Conscious Frames and Altered States

Conscious frames can change.

Sleep, dreaming, anesthesia, meditation, psychosis, intoxication, and neurological injury alter the frame.

Under anesthesia, reportability and integration collapse.

In dreams, self-modeling and world-simulation persist but external sensory coupling weakens.

In meditation, attention and self-modeling may be reorganized.

In psychosis, reality testing and self-boundaries may be disturbed.

These changes show that consciousness is not a fixed substance.

It is a dynamic frame.

Thus:

\[
\boxed{
\text{Consciousness is a variable organization, not a constant inner object.}
}
\]

## 25. Phenomenal-Frame Relativity and Theories of Consciousness

Phenomenal-Frame Relativity is compatible with several scientific theories, without requiring one.

### 25.1 Global Workspace Theory

Consciousness arises when information becomes globally available for report, memory, and control.

### 25.2 Recurrent Processing Theory

Consciousness requires recurrent, stable processing rather than mere feedforward activation.

### 25.3 Integrated Information Theory

Consciousness corresponds to integrated information structures.

### 25.4 Predictive Processing

Consciousness involves generative models with error correction and active inference.

### 25.5 Higher-Order Theories

Consciousness involves meta-representation of first-order states.

Phenomenal-Frame Relativity does not choose among these.

It says that any successful theory must explain how a frame of appearance becomes reportable, stable, and publicly correlatable.
