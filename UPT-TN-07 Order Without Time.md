# Technical Note UPT–TN–07

## Intrinsic Phase Evolution Without Primitive Time: Connecting to Existing Technology Rather Than Starting From Scratch

**Dust LLC — Universal Phase Theory Technical Note**
**August 2026**

---

## 1. This is not a new problem

The question TN-06 surfaced — can an ordering/dynamical structure be defined from $\Phi$ itself, without assuming a primitive time parameter — is not being posed for the first time here. It is the central, decades-old open problem of an established research programme: **causal set theory** (Sorkin and collaborators, since the mid-1980s), whose entire premise is that spacetime is fundamentally a locally finite partial order, with geometry and (eventually, still only partially) dynamics recovered from the order alone.

This matters because UPT's round-1 discrete candidate already contains, unused, exactly the primitive this research needs: $\mathcal X$ was defined as an **update DAG** — a directed acyclic graph, i.e. a locally finite partial order. That is, by definition, a causal set. The connection is not a new construction; it is a recognition that a structure already stipulated in the round-1 candidate is the object an entire field has spent forty years studying. The correct move now is to import what that field has actually established, rather than attempt to re-derive comparable results from nothing.

---

## 2. What the existing literature has actually shown (and what it hasn't)

**Established (order alone, no coordinates, no metric, no primitive time):**
- Approximate manifold dimension can be estimated from a bare partial order via counting statistics — the Myrheim–Meyer dimension estimator, tested below.
- Under a Poisson sprinkling correspondence, a causal set can approximate a Lorentzian manifold with recoverable volume (via element-counting) and approximate causal/light-cone structure (via the order relation itself, which *is* the causal structure by construction — this addresses points 1–4 of the five requirements listed in the proposing document almost for free: the order is intrinsically asymmetric (DAG acyclicity), locally composable (transitivity of a partial order), and — in the sprinkling correspondence — different "observers" (different embeddings/coarse-grainings) recover compatible causal structure by construction).

**Not established, in causal set theory generally, not only in UPT:**
- A derivation of *dynamics* — let alone a symplectic structure — from the bare order, remains open. Classical sequential growth models (Rideout–Sorkin) give a candidate stochastic dynamics for how causal sets grow, but a derivation of a Hamiltonian/symplectic structure comparable to what TN-04–TN-06 were seeking has not been achieved even after decades of dedicated work by a community focused on exactly this question.

**The honest implication:** requesting "derive intrinsic phase evolution without primitive time" as the next UPT technical note is requesting a solution to a problem that has resisted an entire adjacent field for forty years. That doesn't make it the wrong question — TN-06 was right to surface it as the real gap — but it means the correct next step is *connecting UPT to that literature's partial results*, not attempting a fresh derivation of the full answer in one note.

## 3. A concrete, verified test: order alone determines geometric information

To make this connection substantive rather than a citation, the Myrheim–Meyer ordering-fraction statistic was computed directly. For a finite set with only an order relation (no coordinates used in the statistic's definition — only which pairs are related), define
$$
r = \frac{2R}{N(N-1)}, \qquad R = \#\{\text{related pairs}\}.
$$
This was tested against causal sets generated by Poisson sprinklings into $d$-dimensional Minkowski space ($d=1$ through $5$, $N=120$, 8 trials each), using only the causal order relation (no coordinate information given to the statistic itself):

| $d$ (spacetime dimension) | mean $r$ | std |
|---|---|---|
| 1 | 1.0000 | 0.0000 |
| 2 | 0.4992 | 0.0159 |
| 3 | 0.2847 | 0.0183 |
| 4 | 0.1634 | 0.0168 |
| 5 | 0.1054 | 0.0053 |

The $d=1$ result (every pair related — trivial, since a 1-dimensional order has no "spatial" separation to violate the light cone) and the $d=2$ result ($r=0.4992$, matching the known exact Myrheim–Meyer value of $r=1/2$ for $1{+}1$ Minkowski to within simulation noise) confirm the implementation is correct, not merely plausible. This is a genuine "order $\to$ geometric information" bridge, verified numerically, directly applicable to UPT's own DAG substrate without modification.

## 4. What this does and does not resolve for UPT

**Resolved, or at least substantially de-risked:** the specific worry that *any* geometric information requires primitive time is answered — dimension, and (via the broader sprinkling-correspondence literature, cited not re-derived here) approximate volume and causal structure, are extractable from order alone. Four of the five numbered requirements in the proposing document (asymmetry, local composability, some form of intrinsic ordering, and — via the sprinkling correspondence's compatibility properties — cross-observer consistency) have known, worked-out treatments in the causal set literature that UPT can inherit rather than reinvent.

**Not resolved, and should not be presented as resolved:** the symplectic/dynamical question TN-04–TN-06 were actually chasing. Recovering $\omega_\Phi$ from order alone is not a solved problem in causal set theory either. UPT is not behind an established field here in a way specific to its own shortcomings — but it is also not ahead of it, and no note in this sequence should claim to have closed this gap.

## 6. Conclusion

TN-06 correctly identified that the missing ingredient is more fundamental than a coefficient — it's a theory of ordering, not just configuration. This note's contribution is narrower but more honest than attempting to supply that theory from scratch: it shows the primitive UPT needs is already present in the round-1 candidate ($\mathcal X$ as a DAG/causal set), connects that fact to a real, rigorous existing research programme with concrete verified results (dimension recovery, tested above) and known, still-open gaps (dynamics), and recommends against posing "derive evolution without time" as a single bounded technical note. The correct framing going forward is incremental: identify which *specific*, already-solved pieces of causal set theory (dimension and volume recovery, sequential growth dynamics as a candidate stochastic — not yet symplectic — evolution rule) can be imported into the UPT formalism next, rather than treating the full problem as newly open and UPT-specific.
