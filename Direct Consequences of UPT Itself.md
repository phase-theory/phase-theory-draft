Direct consequences of **UPT itself** — meaning consequences of the UPT postulates and operator hierarchy, not of later candidate realizations or desired physics — are the following.

---

## 1. Phase is the primitive structural object

UPT reverses the usual ontological order. Instead of beginning with spacetime, particles, fields, or quantum states, UPT begins with a universal phase configuration

\[
\Phi \in \Gamma(E_\Phi),
\]

over a base \(\mathcal X\) that is not assumed to be spacetime.

Direct consequence:

\[
\boxed{
\text{Spacetime, fields, particles, and observables must be represented as structures generated by } \Phi.
}
\]

They are not primitive inputs.

---

## 2. Physical states are equivalence classes of phase configurations

UPT distinguishes raw phase configurations from physical states. If \(\mathscr G_\Phi\) is the admissible phase-transformation structure, then

\[
\Phi_1 \sim \Phi_2
\quad\Longleftrightarrow\quad
\exists g\in\mathscr G_\Phi:\ \Phi_2=g\cdot\Phi_1.
\]

The physical phase space is therefore

\[
\boxed{
\mathcal P_\Phi
=
\mathcal C_\Phi/\mathscr G_\Phi.
}
\]

Direct consequence:

\[
\boxed{
\text{Absolute phase is not physical; invariant phase structure is physical.}
}
\]

---

## 3. Admissible phase configurations satisfy a universal equation

UPT postulates that not every phase configuration is admissible. Admissible configurations satisfy

\[
\boxed{
\mathscr F[\Phi;\lambda]=0.
}
\]

Direct consequence:

\[
\boxed{
\text{Physical structure is constrained by a universal phase equation, not by arbitrary configuration choice.}
}
\]

---

## 4. Stability determines which structures persist

Given a solution \(\Phi_0\), perturb it:

\[
\Phi=\Phi_0+\delta\Phi.
\]

Linearization gives

\[
\mathscr F[\Phi_0+\delta\Phi]
=
\mathscr F[\Phi_0]
+
\mathscr L_{\Phi_0}\delta\Phi
+
O(\delta\Phi^2).
\]

Since \(\mathscr F[\Phi_0]=0\),

\[
\mathscr L_{\Phi_0}\delta\Phi=0.
\]

The stability operator is

\[
\boxed{
\mathscr L_\Phi
=
D_\Phi\mathscr F.
}
\]

Direct consequence:

\[
\boxed{
\text{Observable structures correspond to stable or metastable phase configurations.}
}
\]

Unstable configurations are not expected to persist as observable structures.

---

## 5. Local phase transitions occur where stability fails

A local critical phase configuration satisfies

\[
0\in\sigma(\mathscr L_\Phi),
\]

or equivalently,

\[
\ker\mathscr L_\Phi\neq 0.
\]

Using a generalized determinant,

\[
\boxed{
\Delta_\Phi
=
\operatorname{Det}_\Phi(\mathscr L_\Phi),
}
\]

the local critical manifold is

\[
\boxed{
\Sigma_\Phi
=
\{\Phi:\Delta_\Phi=0\}.
}
\]

Direct consequence:

\[
\boxed{
\text{Local phase transitions occur where the phase stability operator loses invertibility.}
}
\]

---

## 6. Order parameters are generated by the kernel of the stability operator

Let

\[
K_\Phi=\ker\mathscr L_\Phi.
\]

Choose a basis \(\{e_a\}\). Near criticality,

\[
\delta\Phi
=
\eta^a e_a
+

\[

\eta^a

Direct consequence:

\[
\boxed{
\text{Order parameters are not externally chosen; they are coordinates on } \ker\mathscr L_\Phi.
}
\]

---

If \(\mathscr L_\Phi\) is Fredholm of index zero with finite-dimensional kernel, Lyapunov–Schmidt reduction gives

\[
\xi=\xi(\eta,\lambda),
\]

and therefore

\[
\boxed{

}

Direct consequence:

\[
\boxed{
\text{Near finite-codimension transitions, infinite-dimensional phase structure reduces to finite-dimensional order-parameter equations.}
}
\]

Where \(\mathscr L_\Phi\) is invertible on the noncritical subspace,

\[
\boxed{
\boldsymbol{\chi}_\Phi
=
\left.
\mathscr L_\Phi
\right|_{\perp}^{-1}.

In reduced coordinates, if

\[
S_{ab}
=

\[
\boxed{

=

}

Direct consequence:

\[
\boxed{
\text{Phase response is controlled by the inverse of phase stability.}
}
\]

As stability weakens, susceptibility diverges.

Not all transitions require local instability. If two locally stable branches \(\Phi_r\) and \(\Phi_s\) have equal phase potential,

\[
\boxed{
\Phi_r(\lambda_c)=\Phi_s(\lambda_c),

Direct consequence:

\[
\boxed{
\Sigma_\Phi
=
\Sigma_{\mathrm{loc}}
\cup
\Sigma_{\mathrm{glob}}.
}
\]

Local transitions come from stability failure; global transitions come from branch degeneracy.

d\omega=0.

Direct consequence:

\[
\boxed{
\text{Charge is an invariant of phase structure, not an independently inserted label.}
}
\]

\mathcal A_\mu[\Phi].

\[
\boxed{

=
\partial_\mu A_\nu

Direct consequence:

\[
\boxed{
\text{Gauge curvature is nontrivial phase transport.}
}
\]

Gauge symmetry is interpreted as redundancy in the choice of local phase frame.

\boxed{
\text{Discrete structure can arise from stability, topology, or spectrum.}

## 25. Unrestricted polynomial candidate actions are underdetermined

From UPT-TN-02, if a candidate potential is written as a polynomial in \(N\) invariants of degree \(D\),

\[
V(I_1,\dots,I_N)
=
\sum_{|\alpha|\le D}
c_\alpha I^\alpha,
\]

then the number of coefficients is

\[
\boxed{
P(N,D)
=
\binom{N+D}{D},
}
\]

and excluding the irrelevant constant,

\[
\boxed{
P_{\mathrm{phys}}(N,D)
=
\binom{N+D}{D}-1.
}
\]

If the number of free parameters exceeds or equals the number of target observables, fitting is not prediction.

The sharper criterion is rank. Let

\[
\mathcal O:\Theta\to\mathbb R^M
\]

map theory parameters to observables. Define

\[
r
=
\operatorname{rank}
\left(
\frac{\partial\mathcal O_i}{\partial\theta_j}
\right).
\]

Then:

- if \(r<M\), the theory predicts relations among observables;
- if \(r=M\) with many free parameters, the theory is merely fitting.

Direct consequence:

\[
\boxed{
\text{A UPT candidate realization is predictive only if it yields rank-deficient observable relations or is fixed by independent axioms.}
}
\]
